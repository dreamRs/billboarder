# Show method with proxy

Show method with proxy

## Usage

``` r
bb_proxy_show(proxy, targetIdsValue, options = NULL)
```

## Arguments

- proxy:

  A `billboardProxy` `htmlwidget` object.

- targetIdsValue:

  Name of series to show.

- options:

  Additional options.

## Value

A `billboardProxy` `htmlwidget` object.
