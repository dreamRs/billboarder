# Power ratings for The Avengers.

Data are available in "long" and "wide" format.

## Usage

``` r
avengers

avengers_wide
```

## Format

A data frame with 24 rows and 4 variables:

- group:

  Name of the hero

- axis:

  Power skill

- value:

  Value (1-7)

- description:

  Character description

An object of class `data.frame` with 6 rows and 5 columns.
