# Hide method with proxy

Hide method with proxy

## Usage

``` r
bb_proxy_hide(proxy, targetIdsValue, options = NULL)
```

## Arguments

- proxy:

  A `billboardProxy` `htmlwidget` object.

- targetIdsValue:

  Name of series to hide.

- options:

  Additional options.

## Value

A `billboardProxy` `htmlwidget` object.
