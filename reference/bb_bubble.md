# Bubble property for a Billboard.js chart

Bubble property for a Billboard.js chart

## Usage

``` r
bb_bubble(bb, ...)
```

## Arguments

- bb:

  A \`billboard\` \`htmlwidget\` object.

- ...:

  See
  \<https://naver.github.io/billboard.js/release/latest/doc/Options.html#.bubble\>

## Value

A \`billboard\` \`htmlwidget\` object.
