# SVG property for a Billboard.js chart

SVG property for a Billboard.js chart

``` r
bb_svg(bb, ...)
```

## Arguments

- bb:

  A \`billboard\` \`htmlwidget\` object.

- ...:

  See
  \<https://naver.github.io/billboard.js/release/latest/doc/Options.html#.svg\>

## Value

A \`billboard\` \`htmlwidget\` object.
