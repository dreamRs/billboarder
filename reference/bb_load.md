# Load data to the chart with proxy

Load data to the chart with proxy

## Usage

``` r
bb_load(proxy, data = NULL, unload = NULL, ...)
```

## Arguments

- proxy:

  A `billboardProxy` `htmlwidget` object.

- data:

  A `data.frame` with updated data.

- unload:

  Ids (names) to data to unload.

- ...:

  Arguments passed to method.

## Value

A `billboardProxy` `htmlwidget` object.
