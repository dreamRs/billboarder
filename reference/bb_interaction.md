# Interaction property for a Billboard.js chart

Interaction property for a Billboard.js chart

## Usage

``` r
bb_interaction(bb, ...)
```

## Arguments

- bb:

  A \`billboard\` \`htmlwidget\` object.

- ...:

  See
  \<https://naver.github.io/billboard.js/release/latest/doc/Options.html#.interaction\>

## Value

A \`billboard\` \`htmlwidget\` object.
