# Monthly supply / demand balance (january 2007 to june 2017)

Monthly history of supply/demand balance (GWh) based on gross
consumption, the balance of physical exchanges with foreign countries
and offtakes due to pumping. Last update : 2017-07-27.

## Usage

``` r
equilibre_mensuel
```

## Format

A data frame with 126 rows and 5 variables:

- date:

  Date

- solde:

  Supply/demand balance (in GWh)

- production:

  Generation (in GWh)

- pompage:

  Pumping for hydraulic generation (in GWh)

- consommation:

  Consumption (in GWh)
