# Spline property for a Billboard.js chart

Spline property for a Billboard.js chart

## Usage

``` r
bb_spline(bb, ...)
```

## Arguments

- bb:

  A `billboard` `htmlwidget` object.

- ...:

  See
  <https://naver.github.io/billboard.js/release/latest/doc/Options.html#.spline>

## Value

A `billboard` `htmlwidget` object.
