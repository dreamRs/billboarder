# Transition property for a Billboard.js chart

Transition property for a Billboard.js chart

## Usage

``` r
bb_transition(bb, ...)
```

## Arguments

- bb:

  A `billboard` `htmlwidget` object.

- ...:

  See
  <https://naver.github.io/billboard.js/release/latest/doc/Options.html#.transition>

## Value

A `billboard` `htmlwidget` object.
