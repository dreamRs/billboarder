# French electricity generation by year and branch.

Annual French electricity production (TWh) by branch. Last update :
2017-02-15.

## Usage

``` r
prod_filiere_long
```

## Format

A data frame with 45 rows and 3 variables:

- annee:

  Year

- branche:

  Source of production

- prod:

  Production in TWh

## Source

RTE
(<https://odre.opendatasoft.com/explore/dataset/prod-national-annuel-filiere/>)
